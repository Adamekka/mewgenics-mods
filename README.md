# Mewgenics mods

Mod inventory and management scripts for the ARM64 SteamOS VM.

- [Installed mods](mods.json)
- [Pinned loader and Mewtator source](runtime.json)
- [Usage and recovery](docs/usage.md)
- [SteamOS setup](docs/steamos-setup.md)

Run commands inside the VM from `~/Coding/mewgenics-mods`:

```sh
./manage status
./manage backup
./manage check
./manage update
```

The repo contains the inventory and scripts. Downloaded mods, game files, backups, and API keys stay outside Git.
